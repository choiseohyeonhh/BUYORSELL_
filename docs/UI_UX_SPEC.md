# UI_UX_SPEC — 사용자 경험·화면 명세

버전 0.1 · 관련: `PRODUCT_PLAN.md §4–5`, `QUANT_MODEL_SPEC.md §13–16`, `MODEL_VALIDATION_SPEC.md §3.6, §5.4`

---

## 1. UX 원칙

1. **결론 먼저, 근거는 계층적으로**: 판단 → 기간 → 신뢰도 → 확률 → 요인 → 과거 성과 → 위험 → 상세 차트.
2. **불확실성을 숨기지 않는다**: 확률·신뢰도·표본 부족·데이터 지연을 결과와 같은 시선 높이에 표시.
3. **숫자마다 정의**: 모든 수치에 ⓘ (정의 / 산출식 / 데이터 기준 시각 / 관련 연구 링크).
4. **장식이 데이터처럼 보이지 않게**: 게이지·온도계·"AI 점수" 같은 장식적 시각 요소 금지. 시각 요소는 실제 값과 1:1 대응.
5. **트레이딩 터미널이 아니다**: 한 화면에 한 가지 질문. 다크 패턴·긴박감 유도("지금 사세요") 금지.
6. **시장 관례 존중**: 색상 의미가 한국(상승=빨강, 하락=파랑)과 미국(상승=초록, 하락=빨강)이 반대 → **사용자 설정 + 로캘 기본값**, 색상만으로 의미 전달 금지(아이콘·텍스트 병기).

## 3. 핵심 사용자 흐름

### F1. 검색 → 판단 (목표: 2탭 이내, p75 2초)
```
[홈] → 검색창 탭 → "삼성" 입력 → 자동완성(삼성전자 005930 KOSPI) → [종목 상세: 판단 카드]
```
- 자동완성: 이름·티커·코드·초성(ㅅㅅㅈㅈ), 최근 검색 5개(로컬 저장).
- 유니버스 밖 종목: 상세 페이지에 "분석 대상이 아닙니다 — 사유: 유동성 기준 미달" + 기준 설명.

### F2. 판단 → 근거 → 검증
판단 카드 "왜?" 링크 → ③ 근거 → 요인 탭 → 요인 정의 시트(바텀시트/사이드패널) → "이 요인의 과거 예측력" → 모델 성과 페이지 해당 섹션.

### F3. 데이터 지연·오류
상단 고정 배너: "미국 시장 데이터 업데이트 지연 — 표시된 신호는 2026-11-05 기준입니다."

├───────────────────────────────┤
│ [ 단기 2주 ] [ 중기 3개월 ]    │  탭 (기본: 중기)

(수치는 레이아웃 예시이며 실제 값이 아니다.)

- 카드형 세로 스크롤, 섹션 접기/펼치기(③–⑦ 기본 접힘 여부 [PARAM]: ①② 펼침, 나머지 요약 1줄 + 펼치기).
- 터치 타깃 ≥ 44×44pt, 차트는 핀치 줌 대신 기간 버튼 + 스크럽(길게 눌러 툴팁).
- HOLD 표시: `■ HOLD` + 사유 문구("매수·매도 어느 쪽도 통계적 우위가 없습니다"). HOLD를 회색으로 약하게 표시하지 않는다 — 정보가 있는 판단임.

### 4.1 신호 상태 표기 규칙

| 상태 | 아이콘 | 라벨 | 보조 문구 |
|---|---|---|---|
| BUY | ▲ | BUY | 시장 대비 초과수익 가능성 우위 |
| BUY (유지 중) | ▲ | BUY · 유지 | 진입 기준보다 약해졌지만 이탈 기준 전 |
| HOLD | ■ | HOLD | 사유 코드별 문구 (`QUANT_MODEL_SPEC.md §13.5`) |
| SELL | ▼ | SELL | 시장 대비 부진 가능성 우위 |
| SELL · 위험 | ▼! | SELL · 위험 신호 | 급격한 변동성 확대와 하락 추세 |
| 확인 중 | ◌ | HOLD · 확인 중 | 다음 평가일에 확정 |
| 분석 불가 | — | 데이터 부족 | 사유 |

### 4.2 확률 표시 상태 (`MODEL_VALIDATION_SPEC.md §3.6`)

| 정책 | 표시 |
|---|---|
| FULL | 막대 + 정수 % |
| COARSE | 막대 + 5%p 단위 + "보정 점검 중" 배지 |
| HIDDEN | 막대 숨김, "방향 우위: 강함/보통/약함" + "확률은 보정 검증 후 공개됩니다" |

### 4.3 신뢰도 등급 툴팁 (예시 문구)
"신뢰도는 '상승 확률'과 다릅니다. 이 판단과 비슷한 조건(신호 강도, 엔진 일치도, 데이터 유사성, 시장 국면)에서 과거 판단이 비용을 넘어 맞았던 비율을 바탕으로 A–D 등급으로 나눈 것입니다. 등급별 실제 적중률은 [모델 성과]에서 확인할 수 있습니다."

## 5. 종목 상세 — 데스크톱 (≥ 1200px)

```
┌───────────────────────────────────────────────────────────────────────────────┐
│ BUY OR SELL   [검색.............................]   시장국면: US ▲안정 KR ■  │
├─────────────────────────────┬─────────────────────────────────────────────────┤
│ 삼성전자 005930 · KOSPI     │  ⑥ 차트 (가격·MA·신호 마커 / 거래량 / 변동성)   │
│ ₩xx,xxx +1.2%               │  [1M 3M 1Y 3Y]  [지표: MA200 · 변동성 밴드]      │
│ ┌──────────┬──────────┐     │                                                 │
│ │ 단기 2주  │ 중기 3개월│     │                                                 │
│ │ ■ HOLD   │ ▲ BUY    │     │                                                 │
│ │ 신뢰도 C  │ 신뢰도 B  │     │                                                 │
│ │ 사유:우위 │ 10/24~   │     │                                                 │
│ │ 없음      │          │     │                                                 │
│ └──────────┴──────────┘     │                                                 │
│ ② 확률 (두 기간 나란히)      ├─────────────────────────────────────────────────┤
│ ⑤ 위험 요인                 │ ③ 엔진별 신호 비교 (표)                          │
│                             │  엔진 | 단기 기여 | 중기 기여 | 원 Feature 값 | ⓘ │
│                             ├─────────────────────────────────────────────────┤
│                             │ ④ 과거 유사 신호 분포 · ⑦ 신호 이력 타임라인       │
└─────────────────────────────┴─────────────────────────────────────────────────┘
```
- 좌측 고정(sticky) 판단 패널, 우측 스크롤 분석 영역.
- 엔진 비교 표에서 원 Feature 값(예: MOM_12_1 = +23%, 횡단면 백분위 88%)과 정의 링크.
- 단기·중기 판단이 다를 때(예: 단기 SELL·중기 BUY) 두 카드 사이에 설명: "기간에 따라 근거가 다릅니다: 단기는 최근 급등에 따른 반전 가능성, 중기는 지속적 상대 강도."

## 6. 기타 화면

### 6.1 홈
- 모바일: 검색창 → 시장 국면 카드 2개 → 모델 성과 요약(최근 90일 Short BSS·BUY 초과수익, CI 포함) → 방법론 소개 3줄.
- 데스크톱: 위 + 국면 이력 미니 차트.
- **특정 종목 매수 추천 목록을 홈에 노출하지 않는다** (MVP; 규제·오해 리스크).

### 6.2 시장 국면 페이지
- 현재 국면 코드와 의미, π^HV 시계열(1년), 추세 상태, 시장 폭, 변동성 백분위.
- "국면별 모델 성과" 표 (`BACKTEST_SPEC.md §10.3`)와 연결.

### 6.3 모델 성과 페이지
| 섹션 | 내용 |
|---|---|
| 실시간 성과 (원장 기반) | 시장·기간 선택, 30일/90일/1년/전체 탭, 만기 도래 신호 수, BUY/SELL 신호 평균 초과수익(비용 차감, CI), BSS, 등급별 적중률, 진행 중 신호 수 |
| 확률 보정 | 신뢰도 곡선(클래스별), ECE, 표시 정책 상태 |
| 가상 성과 (백테스트) | 명확히 다른 배경색 + "가상 성과" 라벨. Walk-forward·lockbox 결과, 가정(비용·체결) |
| 국면별 성과 | 표 |
| 표본 부족 | 기준 미달 시 수치 대신 "표본 부족 (n=…, 최소 …)" |

### 6.4 방법론 페이지
모델 카드, 엔진별 정의(수식), 근거 연구 목록(QUANT_RESEARCH 링크), 용어집, 데이터 출처·기준 시각, 한계.

### 6.5 신호 원장 페이지
날짜·시장 선택 → 레코드 목록(종목, 기간, 판단, 해시) → 앵커 해시, 검증 방법 안내.

## 7. 차트 명세

| 차트 | 요소 | 규칙 |
|---|---|---|
| 가격 | 캔들 또는 라인(모바일 기본 라인), MA200, 신호 마커(▲▼■ 상태 전이일) | 로그 스케일 옵션, 조정가 사용 명시 |
| 거래량 | 거래대금 막대, 63일 평균선 | |
| 변동성 | σ̂ 기반 ±1σ 기대 범위 밴드 (기간 h) | "예측 구간이며 보장 아님" 라벨 |
| 확률 막대 | 3개 수평 막대, 0–100% 고정 축 | 축 고정(시각적 과장 방지) |

| 신뢰도 곡선 | 대각선 기준선 + 구간별 점(크기=표본) + CI | |

## 8. 디자인 시스템

### 8.1 토큰
| 토큰 | 값(라이트) | 용도 |
|---|---|---|
| `--bg` | #FFFFFF | 배경 |
| `--surface` | #F7F8FA | 카드 |
| `--text` | #111418 | 본문 |
| `--text-muted` | #5B6472 | 보조 |
| `--border` | #E3E6EB | 구분선 |
| `--accent` | #3049D6 | 링크·포커스 (신호 색과 구분) |
| `--signal-up` | 로캘별: KR #D92D20 / US #12805C | BUY·상승 |
| `--signal-down` | 로캘별: KR #1D5BD8 / US #D92D20 | SELL·하락 |
| `--signal-hold` | #6B5BD2 (중립 보라) | HOLD — 회색 금지(비활성처럼 보임) |
| `--warn` | #B54708 | 위험·지연 |
| `--hypothetical` | #FFF7E0 배경 | 백테스트(가상 성과) 영역 |

다크 모드 별도 팔레트 (대비 4.5:1 이상). 색상 설정: "상승 빨강(한국식) / 상승 초록(미국식)" 사용자 토글.

### 8.2 타이포그래피
Pretendard(한글) / Inter(영문), 숫자 tabular-nums. 판단 라벨 32–40px Bold, 섹션 제목 18px, 본문 15–16px, 보조 13px.

### 8.3 컴포넌트
`SignalBadge`, `DecisionCard`, `ProbabilityBars`, `ConfidenceGrade`, `ContributionBars`, `RiskPanel`, `RegimeChip`, `DefinitionSheet`(ⓘ), `SampleSizeNotice`, `HypotheticalBanner`, `DataStatusBanner`, `DisclaimerFooter`.

### 8.4 접근성 (WCAG 2.2 AA)
- 색상 외 아이콘·텍스트로 상태 구분, 대비 4.5:1.
- 차트는 표 대체 보기 제공(스크린리더).
- 키보드 탐색, 포커스 표시, `prefers-reduced-motion` 존중.

### 8.5 문구 원칙
- 금지 표현: "확실", "보장", "무조건", "AI가 추천", "지금 사야 할".
- 필수 맥락: "시장 대비", "향후 약 N주/개월", "과거 데이터 기반 통계적 판단".
- 투자 위험 고지: 판단 카드 하단 상시 링크 + 첫 방문 시 1회 온보딩 (닫기 가능, 동의 강요 없음) — 문안은 법률 검토 후 확정 (`LEGAL_REGULATORY_REVIEW.md`).

## 10. 성능·상태 처리
- 종목 상세 LCP < 2.5s (모바일 4G 기준), 판단 카드는 서버 렌더링.
- 상태: 로딩(스켈레톤), 데이터 지연(배너), 분석 불가(사유), 오류(재시도), 휴장일(직전 거래일 기준 명시).
