# BACKTEST_SPEC — 백테스트 및 실증 검증 명세

버전 0.1 · 관련: `QUANT_MODEL_SPEC.md`(모델 정의), `MODEL_VALIDATION_SPEC.md`(통계 기준·운영 검증), `DATA_SOURCE_SPEC.md`(데이터)

이 문서는 개발자가 별도 해석 없이 백테스트 엔진과 연구 절차를 구현할 수 있도록 작성한다. [PARAM] 값은 사전 등록 초기값이다.

---

## 1. 원칙

1. **시점 정합성(Point-in-Time)**: 시뮬레이션의 어떤 시점 t에서도 t 이후에 생성·공개·수정된 데이터는 사용 불가.
2. **실행 가능성**: 신호는 데이터가 실제로 확보 가능한 시각 이후에만, 실제로 체결 가능한 가격으로만 거래.
3. **사전 등록**: 모든 실험은 실행 전에 정의(Feature, 파라미터 격자, 평가지표, 채택 기준)를 레지스트리에 기록. 실행 횟수는 다중검정 보정에 반영.
4. **단일 잠금 홀드아웃**: 최종 테스트 구간(lockbox)은 릴리스 후보당 1회만 열람.
5. **비교 기준 필수**: 모든 결과는 기저율·동일가중 결합(EW)·단순 모멘텀·매수보유 대비로 보고.
6. **적중률 ≠ 수익률**: 예측 성능 지표와 투자 성과 지표를 분리 보고.

## 2. 종목 유니버스

- 정의는 `QUANT_MODEL_SPEC.md §2` 그대로 구현. 날짜별 `universe_membership(date, security_id, eligible, exclusion_code)` 테이블을 **먼저 생성**하고 모든 실험이 이를 참조.
- 상장폐지·합병·피인수 종목을 포함한 전체 종목 마스터가 필수 (생존편향 방지).
- 지수 구성 PIT 이력이 없으면 §2.2 시총 상위 규칙 사용. 두 규칙의 결과 차이를 민감도 분석에서 보고.

## 3. 기간과 데이터 분리

### 3.1 전체 기간 [PARAM — 데이터 확보 범위에 따라 확정]

| 시장 | 데이터 시작 | 워밍업 (Feature 계산용) | 평가 시작 | 비고 |
|---|---|---|---|---|
| US | 1998-01 | 1998-01 ~ 2000-12 (RMOM 756일 창) | 2001-01 | 닷컴 붕괴·2008·2020·2022 포함 |
| KR | 2005-01 [VERIFY 상장폐지 종목 포함 데이터 범위] | 2005-01 ~ 2007-12 | 2008-01 | 2008·2011·2020·2022·2024.8 포함 |

### 3.2 분리 구조

```
|── 워밍업 ──|──────────── Walk-Forward 연구 구간 ────────────|── Lockbox ──|── Forward Shadow ──▶
                (학습/검증 반복, 파라미터 선택)                 (최근 24개월)  (실시간, 공개 전 63일+)
```

- **Lockbox**: 설계 동결일 기준 직전 24개월 [PARAM] (예: 동결일이 2027-03-31이면 2025-04-01 ~ 2027-03-31). Walk-forward 연구에서 이 기간 데이터는 라벨·Feature 모두 접근 불가하도록 **데이터 접근 계층에서 차단**(코드 수준 가드: `max_date` 하드 리밋, 우회 시 예외).
- **Forward Shadow**: 운영 파이프라인으로 실제 매일 신호를 원장에 기록하되 공개하지 않는 기간 ≥ 63거래일.

### 3.3 Walk-Forward 설계 (Expanding Window)

```
for each test year Y in [Y0, Y_last_before_lockbox]:
    train_end   = 마지막 거래일 of (Y − 1) − purge_gap
    train_start = 평가 시작일 (고정, expanding)
    calib       = train 구간의 마지막 252(Short)/504(Mid) 거래일  → β 추정에서 제외, Temperature T만 추정
    fit_window  = [train_start, calib_start − purge_gap]
    inner CV    = fit_window 에서 Purged K-Fold (K=5, embargo=h) → λ, δ, GBDT 하이퍼파라미터 선택
    model_Y     = fit(fit_window, 선택된 하이퍼파라미터)
    T_Y         = calibrate(model_Y, calib)
    predict on test year Y (모든 거래일)
concatenate all test-year predictions → OOS 예측 시계열
```
- 첫 테스트 연도 Y0 = 평가 시작 + 최소 학습 기간 [PARAM]: US 2008 (학습 2001–2007, 7년), KR 2013 (학습 2008–2012, 5년).
- 운영 재추정 주기(분기)와 연구 재추정 주기(연간)의 차이는 민감도 분석에서 분기 재추정 버전도 1회 실행해 보고.
- `purge_gap` = h + 1 거래일 (라벨 기간이 테스트 구간과 겹치는 학습 표본 제거).

### 3.4 Purged K-Fold + Embargo (J6)

시계열 순서를 보존한 연속 블록 K개로 분할. 검증 블록 [a, b]에 대해:
- **Purge**: 학습 표본 중 라벨 구간 [t+1, t+1+h]가 [a, b]와 겹치는 t 제거.
- **Embargo**: b 이후 h 거래일의 학습 표본 제거 (검증 블록 직후 정보 누출 방지).
- 무작위 셔플 분할(KFold(shuffle=True), train_test_split) **사용 금지**. 코드 리뷰 체크리스트에 포함.

### 3.5 Rolling Window 비교
확장창 기준선과 함께 롤링창(최근 10년) 버전을 민감도로 1회 실행. 롤링이 유의하게 우월하면(DM 검정) 비정상성 신호로 기록하고 `MODEL_VALIDATION_SPEC.md`의 재학습 정책 검토.

## 4. 시점과 체결 가정

### 4.1 정보 가용 시각

| 시장 | 정규장 종료 | 신호 계산 데이터 컷오프 | 신호 공개 |
|---|---|---|---|
| US | 16:00 ET | 당일 EOD 데이터(벤더 확정치) 수신 후 — 계획 18:30 ET [VERIFY 벤더 EOD 확정 시각] | 20:00 ET |
| KR | 15:30 KST | 18:00 KST (시간외 단일가 종료 후, 정규장 종가 기준) | 19:30 KST |

### 4.2 체결 규칙 (기본 시나리오)

- t일 신호 → **t+1일 시가**에 체결. 종가 기반 신호를 같은 종가에 체결하는 가정 금지.
- 체결가 = O_{t+1} × (1 + slippage) for BUY, O_{t+1} × (1 − slippage) for SELL. slippage = ½·SPREAD_AR + 시장충격 (`QUANT_MODEL_SPEC.md §14.2`).
- 민감도 시나리오: (S1) t+1 종가 체결, (S2) t+1 (O+H+L+C)/4 체결, (S3) t+2 시가 체결(1일 지연).

### 4.3 체결 불가 조건

| 상황 | 처리 |
|---|---|
| KR t+1 시가 = 상한가 & BUY | 체결 불가, 다음 거래일 재시도 (최대 3일, 이후 신호 취소) |
| KR t+1 시가 = 하한가 & SELL | 체결 불가, 다음 거래일 재시도 (청산될 때까지) |
| 거래정지 | 정지 기간 동안 마지막 가격으로 평가, 재개일 시가 체결 |
| 거래량 0 | 체결 불가 처리 |
| 주문 규모 > ADV의 1% (Q_ref 기준) | 체결 허용하되 경고 (개인 규모에선 발생 드묾) |

### 4.4 신호 평가 vs 포트폴리오 평가

1. **신호 단위 평가(Event study)**: 각 신호 발생 (i, t)에 대해 §11.1 라벨 X와 비용 차감 X − c^{rt} 계산. 상태 전이가 일어난 날짜만 "신호 발생"으로 집계(유지 중인 날은 중복 집계하지 않음). 
2. **포트폴리오 평가**: §6.

## 6. 포트폴리오 평가 구성

서비스는 개별 종목 판단을 제공하지만 모델의 경제적 가치는 표준 포트폴리오로 평가한다. 모두 시장·기간별로 산출.

| 포트폴리오 | 구성 | 목적 |
|---|---|---|
| P_BUY_EW | BUY 상태 종목 동일가중, 상태 변경 시에만 거래 | **주 평가 대상** (사용자가 BUY만 따를 때) |
| P_BUY_IV | BUY 상태 종목 1/σ̂ 가중 | 위험 조정 비교 |
| P_AVOID | 유니버스 동일가중에서 SELL 상태 종목 제외 | SELL의 가치 (회피 효과) |
| P_LS (연구용) | BUY − SELL 동일가중 | 순수 예측력 (공매도 가정, 사용자 비노출) |
| Q1…Q5 | E (=p_up − p_down) 5분위, 평가일마다 리밸런싱 | 순위 예측력, 단조성 |
| BENCH | 벤치마크 ETF 매수보유, 유니버스 동일가중 매수보유 | 기준 |
| BASE_MOM | MOM_12_1 상위 20% 동일가중, 월간 | 단순 전략 기준선 |
| BASE_EW | EW 결합 모형으로 동일한 결정 엔진 적용 | 앙상블 가치 측정 |
| RANDOM | BUY 신호와 같은 빈도·보유기간의 무작위 신호 1,000회 | 귀무 분포 |

현금은 무위험수익률(US: 3개월 T-bill, KR: CD 91일)로 운용 가정.

## 7. 성과 지표 (정의)

r_p: 포트폴리오 일 단순수익, r_b: 벤치마크, rf: 무위험, T: 일 수, A = 252.

### 7.1 수익성
| 지표 | 정의 |
|---|---|
| Total Return | Π(1+r_p) − 1 |
| CAGR | (Π(1+r_p))^{A/T} − 1 |
| Annualized Return | A · mean(r_p) (산술) |
| Excess Return | CAGR_p − CAGR_b, 그리고 연율 초과수익 A·mean(r_p − r_b) |

### 7.2 위험
| 지표 | 정의 |
|---|---|
| Volatility | sqrt(A)·sd(r_p) |
| Downside Deviation | sqrt(A · mean(min(r_p − rf, 0)²)) |
| Maximum Drawdown | max_t (1 − W_t / max_{s≤t} W_s), W = 누적 자산 |
| VaR95 (1일, 역사적) | −quantile_{5%}(r_p) |
| CVaR95 | −mean(r_p \| r_p ≤ quantile_{5%}) |

### 7.3 위험 조정
| 지표 | 정의 |
|---|---|
| Sharpe | sqrt(A)·mean(r_p − rf)/sd(r_p − rf), 표준오차는 Lo(2002) 자기상관 보정 |
| Information Ratio | sqrt(A)·mean(r_p − r_b)/sd(r_p − r_b) |
| Sortino | A·mean(r_p − rf) / Downside Deviation |
| Calmar | CAGR / MDD |
| Deflated Sharpe Ratio | J4 정의 (시행 수 N = 레지스트리 누적 실험 수, 왜도·첨도 반영) |

### 7.4 예측 성능 (신호 단위, OOS)
| 지표 | 정의 |
|---|---|
| Log-loss | −mean log p_{Y} |
| Brier (다중) | mean Σ_k (p_k − 1[Y=k])² |
| RPS (순서형) | mean Σ_{k} (CDF_p(k) − CDF_Y(k))² |
| Brier Skill Score | 1 − Brier_model / Brier_climatology (기저율 = 학습창 클래스 빈도) |
| ROC-AUC | UP vs rest, DOWN vs rest (one-vs-rest) |
| Directional Accuracy | BUY/SELL 신호에서 sgn(X) 일치 비율 (FLAT 제외 버전 병기) |
| Precision/Recall/F1 | BUY 판정의 Precision = P(Y=UP \| BUY), Recall = P(BUY \| Y=UP); SELL 동일 |
| Calibration | ECE (10개 동일표본 구간), 신뢰도 곡선 기울기·절편 (`MODEL_VALIDATION_SPEC.md §3`) |
| IC | 날짜별 Spearman(E, X) 평균과 Newey-West t |

### 7.5 거래 성과
Win Rate(비용 차감 X > 0 비율), Profit Factor(Σ양의 X / \|Σ음의 X\|), Average Win / Average Loss, Turnover(연간 편도 매매 금액 / 평균 자산), 거래 수, 평균 보유기간.

### 7.6 보고 규칙
- 모든 비율 지표에 **정상 블록 부트스트랩(J7, 평균 블록 길이 = h) 95% 신뢰구간** 병기.
- 신호 단위 통계의 표준오차는 **날짜 클러스터**(동일일 횡단면 상관) + Newey-West(lag = h).
- "적중률 60%" 같은 수치는 반드시 기저율(해당 클래스 무조건 빈도)과 함께 보고.

## 8. 편향·오류 방지 — 구현 체크리스트

| 오류 | 방지 장치 | 자동 테스트 |
|---|---|---|
| Look-ahead bias | Feature 함수는 `as_of` 인자를 받아 그 이전 데이터만 조회하는 데이터 접근 API로만 구현 | **절단 일치 테스트**: 무작위 200개 (i, t)에 대해 데이터를 t까지 잘라 계산한 Feature == 전체 데이터로 계산한 t 시점 Feature (허용오차 1e−12) |
| 라벨 누출 (Leakage) | 라벨 테이블과 Feature 테이블 물리 분리, 모델 학습 함수만 조인 | **라벨 셔플 테스트**: 날짜 내 라벨 무작위 섞기 → OOS AUC가 0.5 ± 0.01 |
| Survivorship bias | 상장폐지 포함 종목 마스터, PIT 유니버스 | 유니버스 내 상장폐지 종목 비율이 공개 통계 대비 합리적 범위인지 검사, 연도별 상장폐지 수 리포트 |
| Overfitting | 사전 등록, 고정 격자, 평탄 영역 선택, DSR, PBO | 레지스트리 시행 수 자동 집계 |
| Data snooping / Multiple testing | SPA(J2), MCS(J3), FDR(J11), t>3 기준(L2) | 검정 스크립트 표준화 |
| Selection bias | 실패 실험도 레지스트리에 기록·보고 | 레지스트리 append-only |
| PIT 데이터 오류 | 수정(revision) 이력 보존, 데이터 스냅샷 해시 | 스냅샷 간 과거 값 변경 감지 리포트 |
| Corporate action 오류 | 조정계수 자체 재계산 대조 (§5.7) | 일별 \|r\| > 50% 이벤트 수동 검토 큐 |
| Timezone/캘린더 오류 | 시장별 거래 캘린더 테이블, 모든 시각 UTC 저장 | 휴장일 데이터 존재 시 실패 |
| 동일 종가 체결 | 엔진이 체결가로 t일 가격 요청 시 예외 | 단위 테스트 |
| 스무딩 국면 확률 사용 | HMM API에 smoothing 함수 노출 금지 | 절단 일치 테스트 포함 |

## 11. 검증 방법 조합 (최종 선정)

| 방법 | 채택 | 용도 |
|---|---|---|
| In-Sample | 진단만 | 계수 부호·적합도 확인; 성과 주장에 사용 금지 |
| Walk-Forward Expanding | **주 방법** | OOS 예측 시계열 생성 |
| Rolling Window | 민감도 | 비정상성 진단 |
| Purged K-Fold + Embargo | **내부 하이퍼파라미터 선택** | λ, δ, GBDT |
| CSCV (J5) | **채택** | PBO 추정: OOS 예측 성과 행렬을 S=16 블록으로 나눠 조합 |
| Stationary Bootstrap (J7) | **채택** | 모든 지표 CI |
| Monte Carlo | **채택** | (a) RANDOM 귀무 분포 (b) 거래 수익 블록 리샘플로 MDD 분포 (c) 비용·지연 파라미터 무작위화 |
| Stress Test | **채택** | §10.2 구간, 비용 ×2/×3, 1일 지연, 상위 1% 승자 거래 제거, 파라미터 ±20% 섭동 |
| Lockbox | **채택 (1회)** | 최종 OOS 확인 |
| Forward Shadow | **채택** | 실시간 운영 검증 |

## 12. 출시 채택 기준 (사전 등록, 시장 × 기간별)

릴리스 후보 모델은 다음을 **모두** 만족해야 해당 시장·기간 조합을 공개할 수 있다. 미충족 조합은 비공개 또는 "Beta(검증 미완)" 표시 — 결정은 `DEVELOPMENT_ROADMAP.md` Gate G4에서.

| # | 기준 | 구간 |
|---|---|---|
| C1 | OOS 로그손실이 기저율 대비 우월, DM 검정 p < 0.05 | Walk-forward |
| C2 | Champion이 EW 기준 대비 열등하지 않음 (DM p > 0.10 이면 EW 채택) | Walk-forward |
| C3 | 보정 후 ECE ≤ 0.03, 신뢰도 기울기 ∈ [0.8, 1.2] | Walk-forward |
| C4 | BUY 신호 비용 차감 평균 초과수익 > 0, 날짜 클러스터 HAC t > 2.0 | Walk-forward |
| C5 | P_BUY_EW 비용 차감 초과수익의 DSR ≥ 0.95 | Walk-forward |
| C6 | PBO < 0.20 | CSCV |
| C7 | 어떤 단일 연도도 누적 초과수익의 40% 초과 기여하지 않음 | Walk-forward |
| C8 | Lockbox에서 C1, C3 충족 및 C4 부호 일치, 성과가 walk-forward 부트스트랩 분포 90% 구간 내 | Lockbox |
| C9 | Forward shadow 63거래일 BSS·초과수익이 walk-forward 분포 하위 5% 밖 | Shadow |
| C10 | §8 자동 테스트 전부 통과 | CI |

이 기준은 **모델 성과의 예측이 아니라 통과 조건**이다. 미달 결과도 그대로 보고한다.

quant/backtest/

  events.py          # 신호 단위 이벤트 평가 (§4.4)
  metrics.py         # §7 지표 + 부트스트랩 CI
