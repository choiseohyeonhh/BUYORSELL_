# DEVELOPMENT_ROADMAP — 개발 로드맵

버전 0.1 · 기간은 소규모 팀(퀀트 1–2, 엔지니어 2, 디자이너 0.5) 가정의 **추정치**이며 약속이 아니다. 각 Phase는 **Gate 조건 충족 시에만** 다음으로 진행한다 — 일정보다 Gate가 우선.

---

## 1. 전체 흐름

```
Phase 0 데이터 기반 ──▶ Phase 1 연구 재현 ──▶ Phase 2 엔진·앙상블 ──▶ Phase 3 백테스트·검증
   (G0)                   (G1)                    (G2)                    (G3: walk-forward 기준)
                                                                              │
Phase 6 출시·운영 ◀── Phase 5 웹 MVP ◀── Phase 4 Lockbox·그림자 운영 ◀────────┘
   (G6)               (G5)                 (G4: lockbox·shadow 기준)
   
※ Phase 5(웹)의 UI 개발은 Phase 2부터 병행 가능 (목업 데이터), 공개는 G4·G5 이후.
```
